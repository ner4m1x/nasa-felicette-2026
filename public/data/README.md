# public/data

Files in this folder are **generated by the Python pipeline** (`scripts/global_scan.py`). **Never hand-edit them.**

Expected outputs (none published yet):

| File | Content |
|---|---|
| `deck.json` | Ranked-candidate deck, schema = `DeckCard` in `src/lib/types.ts` |
| `scan_{targetId}.png` | Web Mercator similarity overlay, bounds `[[-85.0511,-180],[85.0511,180]]` |
| `scan_grid.bin` | Per-cell scores for the point inspector (`src/lib/scanGrid.ts`) |
| `validation_report.json` | Validation badge data for the Mission Report |

Dev fixtures do **not** live here — they live in `src/data/fixtures/` and are blocked in production builds.
